# StudyMate 📚

StudyMate is a Python-based study management application built using Streamlit and SQLite.

## Features

- **Dashboard:** Central place to access study features.
- **Notes:** Create and manage study notes.
- **Study Planner:** Organize study schedules.
- **Quiz:** Test your knowledge.

## Technologies Used

- Python
- Streamlit
- SQLite
- Git and GitHub

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required dependencies.
4. Run the application.

```bash
python -m streamlit run app.py
```

## Database

StudyMate uses SQLite for local data persistence.
